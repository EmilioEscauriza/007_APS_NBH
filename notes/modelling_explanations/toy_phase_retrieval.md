# toy_phase_retrieval.py

Minimal HIO + ER phase retrieval demo using the BCDI forward model as the ground-truth data source.

## Purpose

Build intuition for iterative phase retrieval by running HIO and ER on synthetic 3D coherent diffraction data generated by `bragg_forward_model.py`. The ground-truth object (shape + strain) is known, so the reconstruction quality can be verified directly.

## Algorithm

The script alternates between two constraints:

### Fourier-space constraint

Replace magnitudes of the current estimate's FFT with the measured values, keeping the estimated phases:

$$\Psi'(\mathbf{Q}) = \sqrt{I(\mathbf{Q})} \; \frac{\Psi(\mathbf{Q})}{|\Psi(\mathbf{Q})|}$$

### Real-space constraint

**HIO** (first `n_hio` iterations): inside the support, accept the new estimate; outside, apply feedback:

$$\psi_{n+1}(\mathbf{r}) = \begin{cases} \psi'_n(\mathbf{r}) & \mathbf{r} \in S \\ \psi_n(\mathbf{r}) - \beta\,\psi'_n(\mathbf{r}) & \mathbf{r} \notin S \end{cases}$$

**ER** (final `n_er` iterations): set $\psi = 0$ outside the support.

### Error metric

The R-factor measures agreement between estimated and measured Fourier magnitudes:

$$R = \frac{\sqrt{\sum ||\hat\Psi| - \sqrt{I}|^2}}{\sqrt{\sum I}}$$

### Twin resolution and global phase alignment

Phase retrieval has inherent ambiguities: a global phase offset and the conjugate/inversion twin ($\psi^*(-\mathbf{r})$ gives the same diffraction pattern). The script tests all four twin candidates (direct, conjugate, inverted, conjugate-inverted), aligns each to the ground truth by removing the mean phase offset, and picks the one with the best phase correlation.

## Usage

### Default (64^3 sphere with 0.2% strain, 200 HIO + 50 ER)

```bash
python modelling/toy_phase_retrieval.py
```

### Custom parameters

```bash
python modelling/toy_phase_retrieval.py --grid-size 128 --shape cube --strain-xx 5e-3 --hio-iters 300
```

### CLI options

```
--grid-size      N for N×N×N grid (default 64)
--particle-size  Particle diameter [nm] (default 150)
--shape          sphere | cube (default sphere)
--strain-xx      ε_xx strain component (default 2e-3)
--hio-iters      Number of HIO iterations (default 200)
--er-iters       Number of ER iterations (default 50)
--beta           HIO feedback parameter (default 0.9)
--seed           Random seed for initial guess (default 42)
```

## Output

A 2×3 figure:

- **Top row**: central-slice amplitude — ground truth vs reconstruction.
- **Bottom row**: central-slice phase (inside support) — ground truth vs reconstruction.
- **Top right**: R-factor convergence curve with HIO→ER transition marked.
- **Bottom right**: reconstructed amplitude with support contour overlaid.
